How to use this kit

Read in 20 minutes. Use this week. Each prompt page is a working template with full META / INPUT / OUTPUT and an expected-output reference card you can score against.

The teacher-in-the-loop rule for marketing

AI drafts. You decide. Treat every output as a first draft that needs a fact check, brand pass, and publish gate. AI cannot tell you what is true about your customers, your numbers, or your market. Only you can.

Prompt loading order (do this once)

  1. Fill the marketing context block (page 6) once for your brand.
  2. Pick the prompt that matches your job (pages 7–16).
  3. Paste context block as CONTEXT: on top, then the prompt body.
  4. Score the result against the expected outputs (page 17).
  5. Run the pre-publish reviewer (page 21) before anything ships.

What to do if a prompt fails

  • Output is generic, no audience texture - tighten INPUT: name a city, a role, a number.
  • Output rambles - tighten OUTPUT: name the shape, the length, and the sections.
  • Output sounds confident but vague - add "include a verification flag for any unsupported claim".
  • Output keeps drifting - swap the model (ChatGPT to Claude or Gemini) and rerun with the same prompt.
  • If two revisions do not fix it, write that part yourself and move on.

Privacy reminder. Public AI tools are not approved data systems. Do not paste customer PII, internal financials, NDA content, or board-confidential material. Use general non-identifying context only.

The marketing context block

The single biggest leverage in this kit. Fill these 5 fields once and reuse them on every prompt - that one move turns generic output into your-brand output.

FieldWhat to writeCommon mistakes
AudienceSpecific role + market + pain. "VP RevOps at US B2B SaaS, $20-150M ARR, struggles with revenue forecast accuracy.""SMBs", "B2B", "marketers" - too broad to act on.
OfferWhat you sell + the outcome it produces in one sentence. Include price band if it changes the angle.Listing features instead of the buyer outcome.
ChannelsPrimary + secondary, with a constraint per channel (length, time, frequency).Listing every channel you have ever used.

Paste this above any prompt

CONTEXT:
- Audience: [specific role + market + pain]
- Offer: [what we sell, outcome it produces]
- Channels: [primary, secondary, constraint per channel]
- Goal: [one KPI + target window]
- Constraint: [brand voice, legal, time, budget]

- Do not invent customer names, numbers, or quotes.

Prompt 1 of 10 - Plan

30-day content system

~8 min Monthly Plan

Full prompt body

META: You are a US market content strategist. Goal: build a 30-day plan using 4 pillars (Authority, Problem, Proof, Offer).

INPUT: Audience [ ], pain point [ ], unique selling proposition [ ], channel [ ], target city [e.g., Austin, Miami, Chicago]. Include weekly budget ranges in $ when relevant.

OUTPUT: A 30-day table with topic, hook, format, CTA, KPI, and expected outcome. Keep tone practical for US B2B buyers.

Expected output (score against this)

  • 30-day table: topic, hook, format, CTA, KPI.
  • Weekly themes mapped to 4 pillars (Authority, Problem, Proof, Offer).
  • One next action for week 1 with owner and deadline.

Operator notes

  • Run weekly, not just monthly - update only the upcoming 7 days based on Friday analysis.
  • If output is generic, tighten INPUT with a target city or industry vertical.
  • Keep one pillar dominant per week. Mixing all four every week dilutes the narrative.
  • Pair with prompt 5 (Action -> Decision) on Friday to feed next week's plan.

Prompt 2 of 10 - Create

One idea -> 7 formats

~6 min Weekly Repurpose

Full prompt body

META: You are a cross-channel strategist. Goal: turn 1 core idea into 7 high-performing formats for US audiences.

INPUT: Core idea [ ], audience [ ], offer [ ], channel priorities [ ]. Keep one message while adapting language by channel.

OUTPUT: 7 assets: LinkedIn post, carousel, 30-sec short video, email, landing hero, ad copy, and 3 hooks. Make examples sound native in US business context.

Expected output (score against this)

  • 7 native US-context assets: LinkedIn post, carousel, 30-sec script, email, landing hero, ad, 3 hooks.
  • Same core message across channels with channel-fit tweaks.
  • 3 ready-to-test hooks with one chosen recommendation.

Operator notes

  • Bring one verifiable proof point into the core idea before running this prompt.
  • If two formats sound identical, you didn't adapt the language - rerun with channel constraints (LinkedIn = trust, video = scroll-stop, email = action).
  • Reuse the 3 hooks as A/B tests on next week's LinkedIn post (prompt 3).

Prompt 3 of 10 - Create

LinkedIn authority post

~4 min 2-3x weekly Trust

Full prompt body

META: You are a LinkedIn authority writer for US B2B. Goal: draft a trust-building post backed by proof.

INPUT: Topic [ ], proof point [number or customer outcome], city/market context [optional]. Target 150-200 words.

OUTPUT: 1 post with hook, 3 clear points, 1 concrete example, and CTA. Write like a sharp operator, not corporate fluff.

Expected output (score against this)

  • 1 LinkedIn post (150-200 words) with hook, 3 points, example, CTA.
  • Concrete proof point cited (number or customer outcome).
  • Verification flag for any unsupported claim.

Operator notes

  • The proof point is the post. Without it, the post is a generic LinkedIn essay.
  • If your proof is "feels like" - go pull a number or kill the post.
  • The CTA should ask one specific question or offer one concrete next step. "DM me" is not a CTA.
  • Re-run the same prompt every Sunday with that week's customer wins.

Prompt 4 of 10 - Create

30-second video script

~4 min Weekly Short-form

Full prompt body

META: You are a short-form video scriptwriter (Reels/TikTok/Shorts). Goal: produce a 30-second script that stops the scroll.

INPUT: Topic [ ], example [ ], audience [ ]. Hook must land in 0-2 seconds.

OUTPUT: Timestamped script: 0-2s hook, 3 key beats, proof/example, CTA. Keep it punchy and natural for US social feeds.

Expected output (score against this)

  • 30-second timestamped script: 0-2s hook, 3 beats, proof, CTA.
  • Visual or B-roll cue per beat.
  • One alternate hook for A/B testing.

Operator notes

  • Read aloud at 1.5x speed - if you cannot say it cleanly, the camera will not say it cleanly either.
  • Replace any "industry term" with the buyer's verb. Buyers do not search for "demand gen", they search for "more meetings".
  • Keep the same 3 beats consistent across the week's videos. Audience pattern recognition compounds.

Prompt 5 of 10 - Improve

Daily analysis (Action -> Decision)

~8 min Friday Decisions

Full prompt body

META: You are a performance analyst. Goal: convert metrics into tomorrow's action plan.

INPUT: Metrics [CTR, CAC, CPL, conversion rate], channels [ ], period [ ], goals [ ]. Include $ impact where possible.

OUTPUT: 4 blocks: (1) What's underperforming, (2) Why (hypothesis), (3) What to test next, (4) What to pause. Use plain US business language.

Expected output (score against this)

  • What is underperforming with $ or % impact.
  • Hypothesis for why, separated from facts.
  • Next test (this week) and what to pause now.
  • Owner and decision deadline.

Operator notes

  • Keep "fact" and "hypothesis" in different sentences. Mixing them is the most common analysis mistake.
  • Cap "next test" at one per channel. Three tests = no test.
  • Always pair "what to test" with "what to pause" - free up the calendar.
  • Feed the output back into prompt 1 on Monday morning.

Prompt 6 of 10 - Convert

Objection handling

~6 min Quarterly + ongoing Sales-marketing

Full prompt body

META: You are a conversion copy specialist. Goal: turn objections into trust-building content that closes deals.

INPUT: Top objections [ ], product/offer [ ], audience [ ]. One objection per content unit.

OUTPUT: 10 pieces (posts, emails, landing snippets): objection, reframing angle, proof, CTA. Tone: direct, empathetic, confident.

Expected output (score against this)

  • 10 content units, one per top objection.
  • Per unit: objection, reframing angle, proof, CTA.
  • Channel suggestion per unit (post, email, landing snippet).

Operator notes

  • Pull objections from recorded sales calls or lost-deal interviews. Survey data is too clean.
  • Reframe is not denial - acknowledge the concern in the buyer's language first.
  • Schedule one objection-led asset per week into the calendar from prompt 1.

Prompt 7 of 10 - Convert

Lead magnet + DM sequence

~8 min Per launch Demand gen

Full prompt body

META: You are a demand-gen specialist. Goal: create 1 lead magnet post plus a 4-step DM follow-up sequence.

INPUT: Lead magnet [what it gives + what it solves], audience [ ], offer [ ]. Sequence flow: opener -> qualify -> value -> offer.

OUTPUT: (1) Post: hook, value, CTA. (2) Four DM messages with clear next step. Keep language US-native and conversion-focused.

Expected output (score against this)

  • 1 lead-magnet post: hook, value, CTA.
  • 4-step DM sequence: opener, qualify, value, offer.
  • Clear next step in every message.

Operator notes

  • The opener earns the second message. Lead with curiosity about their situation, not your offer.
  • The qualify message is the most-skipped step - and the one that protects your calendar.
  • If the magnet "what it solves" is generic, the whole sequence fails. Spend the time there.

Prompt 8 of 10 - Prove

Customer story

~10 min Per win Proof

Full prompt body

META: You are a case-study writer for B2B sales enablement. Goal: turn raw data into a customer story that drives trust and action.

INPUT: Customer [ ], problem [ ], solution [ ], process [ ], results [numbers/quotes], city/market [optional].

Prompt 10 of 10 - Control center

Master prompt

~12 min Quarterly + monthly All together

Full prompt body

META: You are a marketing operations strategist. Goal: build one control-center plan covering content, repurposing, testing, and weekly priorities.

INPUT: Business [ ], audience [ ], pain point [ ], unique selling proposition [ ], revenue goal [ ], channels [ ], data [metrics, objections, stories].

OUTPUT: 6 blocks: (1) 30-day plan, (2) 5 content assets for this week, (3) one idea -> 7 formats, (4) 3 test hypotheses, (5) KPI reading guide, (6) 3 actions for tomorrow by priority. Keep it execution-ready for US teams.

Expected output (score against this)

  • 30-day plan + 5 content assets for this week.
  • 1 idea expanded into 7 formats.
  • 3 test hypotheses with success criteria.
  • 3 prioritised actions for tomorrow with owners.

Operator notes

  • Use this once a quarter to set direction, then again at the start of every month.
  • Block 6 ("3 actions for tomorrow") is the only block that ships work this week. Defend it.
  • If output crosses three pages, you fed it too much - cut the data input by half and rerun.

Scenario 1 of 3

Weekly review (Friday close)

When the week ends and you have 30 minutes to make next week useful.

Brief (paste into your AI tool)

You are my marketing analyst. Last week's metrics: [PASTE NUMBERS OR SCREENSHOT SUMMARY]. Audience: [AUDIENCE]. Channels: [CHANNELS].

Give me:
(1) the single biggest insight from the data,
(2) three prioritized actions for next week with owner + deadline,
(3) one metric to watch and why.

Bottom line

Three actions beat ten vague ideas - ship the smallest test that reduces uncertainty.

Risks the AI will not flag for you

  • Cherry-picking one spike without checking sample size.
  • Optimizing vanity metrics (likes) instead of pipeline or revenue signals.

Questions to ask after the AI replies

  • Which number changed week-over-week and by how much?
  • What did we intentionally not do last week that could explain the result?

Next action

Schedule a 20-minute metrics review with the owner named for action #1.

Scenario 2 of 3

Campaign launch brief

When a new campaign needs a defensible structure before any creative is shipped.

Brief (paste into your AI tool)

You are my campaign lead. Objective: [ONE SENTENCE GOAL]. Audience: [AUDIENCE]. Offer: [OFFER]. Channels: [CHANNELS]. Budget/time box: [CONSTRAINT].

Produce:
(1) core message in one line,
(2) three hook variants aligned to the objective,
(3) channel-specific tweaks (max 2 bullets per channel),
(4) KPIs with targets and measurement window.

Bottom line

One objective, one primary KPI - everything else is diagnostic.

Risks the AI will not flag for you

  • Hooks that promise outcomes we cannot substantiate.
  • Too many KPIs so nobody owns the primary metric.

Questions to ask after the AI replies

  • What would make us stop or pivot this campaign?
  • What proof do we need before we scale creative or budget?

Next action

Pick one hook + one channel for a 7-day pilot before scaling spend.

Scenario 3 of 3

Stakeholder update

When you need a yes/no decision from a stakeholder who has 30 seconds before their next meeting.

Brief (paste into your AI tool)

You are my communications partner. I need a stakeholder update for [AUDIENCE / ROLE]. Decision needed: [YES/NO OR CHOICE]. Context: [2-4 bullets]. Risks: [BULLETS].

Produce:
(1) bottom line in 2 sentences,
(2) recommendation with trade-offs,
(3) explicit ask (decision, budget, or timeline),
(4) next meeting or follow-up if no reply.

Bottom line

If the decision is not obvious in 30 seconds, rewrite the top.

Risks the AI will not flag for you

  • Burying the ask below background.
  • Soft language that avoids ownership or dates.

Questions to ask after the AI replies

  • What happens if we do nothing for two weeks?
  • Who can approve this on their own authority?

Next action

Send the draft and put the decision deadline in the subject line.

Quality gate

Pre-publish risk reviewer

A second-pass prompt that audits any draft before it ships. Run this on every customer-facing asset.

Reviewer prompt

META: Act as a marketing risk reviewer for US B2B audiences. Goal: surface what we cannot defend.

INPUT: [PASTE DRAFT]. Brand voice: [SHORT NOTE]. Constraints: [LEGAL, COMPLIANCE, NDA, BRAND].

OUTPUT:
(1) Three biggest risks (claim, brand, legal, audience).
(2) For each risk: why it is risky + a safer rewrite.
(3) Three claims that need a citation before publishing.
(4) Verdict: SHIP / REVISE / PULL with one-sentence reason.

5-point publish gate (apply after the reviewer pass)

  1. Substantiated. Every number, name, date, quote has a source you can name.
  2. On-brand. Voice and claims match guidelines; no accidental superlatives.
  3. Legally clean. No PII, NDA content, harmful comparisons, undisclosed endorsements.
  4. Reader-aware. Reads in the audience role, market, week.
  5. Owned. Initials and date in the doc.

Verdict policy. SHIP = ready as-is. REVISE = one named change before ship. PULL = do not publish, escalate or kill. Track these counts weekly to spot drift.

Operating plan

30-day deep dive

A defensible 30-day plan stitched from prompts 1, 5, and 10. Use it once at the start of every month, then update only the upcoming week.

WeekPillar focusDaily blocks (20-30 min)
Week 1 Authority - the unique POV your team holds. Mon: Prompt 1. Tue: Prompt 3 (with last quarter's biggest result). Wed: Prompt 2 (one idea -> 7). Thu: Prompt 4 (video). Fri: Prompt 5.
Week 2 Problem - articulate the buyer's pain in their own words. Mon: refine plan. Tue: Prompt 6 (top 3 objections). Wed: Prompt 8 (one customer story). Thu: Prompt 4. Fri: Prompt 5.
Week 3 Proof - earn trust with verifiable outcomes. Mon: refine plan. Tue: Prompt 3 with this week's customer win. Wed: Prompt 8 (second story). Thu: Prompt 9 (cluster). Fri: Prompt 5.

Decision points

  • End of week 1: Did we ship one Authority asset with a verifiable proof point? If no, drop a pillar this month.
  • End of week 2: Are we hearing the same objection twice? Promote it to next month's plan.
  • End of week 3: Is there a customer story that closed a deal? Capture it before the win goes cold.
  • End of week 4: Did the Offer week move the primary KPI? Document the cause - good or bad.

Quality gate

Output quality rubric (1-4)

Score every prompt output 1-4 on each criterion. Average below 3.0? The prompt or the model is wrong, not the topic.

Criterion1 - Beginner2 - Developing3 - Proficient4 - Strong
Specificity Generic, no audience texture. Names role + market. Names role, market, pain, channel constraint. Plus a verifiable proof point and a concrete example.
Structure Wall of text. Headings only. Headings + bullets matching expected output. Hits 3/3 expected bullets with no filler.
Substantiation Confident but unverifiable claims. Some claims flagged. All claims marked [VERIFY] or sourced. Every number, name, date has a source you can name.
Brand fit Generic corporate voice. Approximates voice in 1 sentence. Voice consistent across the asset. Voice + offer language match guidelines line by line.
Action No CTA or vague "DM me". CTA present but generic. CTA names one specific next step. CTA has owner + deadline; ties to a tracked KPI.

How to use the rubric this month

  • Pick 5 outputs at random from this week. Score each (5 numbers 1-4).
  • Find the lowest-average criterion across the 5. That is your prompt-tuning target for next week.
  • If the same criterion stays low for 3 weeks, the prompt is the problem - rewrite the OUTPUT line.

How others use it

Three composite case studies

Composite, not customer-named. Drawn from pilot use across US B2B teams. Adapt to your context.

Case A - B2B SaaS, $20-150M ARR, RevOps audience

Setup. Marketing team of 3, weekly LinkedIn cadence + monthly demand-gen campaign. Primary KPI: SQL volume.

What they ran. Prompt 1 monthly + Prompt 3 twice weekly + Prompt 5 every Friday. Quarterly: Prompt 9 (cluster), Prompt 10 (master).

Outcome by week 6. Cadence held five weeks straight (a first); two LinkedIn posts cited a verifiable customer outcome; Friday review cut paid-search budget on one underperforming campaign and redirected to a content pilot - net effect on SQL TBD, but accountability moved from "marketing reports" to "marketing decides".

Case B - Services firm, 12 partners, growth-led marketing of one

Setup. Lead marketer reports directly to founder, no team. Primary KPI: discovery calls booked.

What they ran. Prompt 7 (lead magnet + DM) for two service lines. Prompt 8 weekly to capture a customer win as it happens. Prompt 6 quarterly with the top 5 lost-deal objections.

Outcome by week 8. One customer story closed a $30K engagement directly attributed to the asset. The DM sequence raised reply rate from generic "interested" to qualified-by-message-3.

Case C - Ecommerce, DTC, growth team of 5

Setup. Heavy on paid social, weak on owned channels. Primary KPI: blended CAC.

What they ran. Prompt 4 daily for Reels/Shorts + Prompt 2 weekly for repurposing one creative angle. Prompt 5 daily with paid-social cohort numbers.

Outcome by week 4. Owned-channel test surfaced a hook that beat paid creative on CTR; team redirected 10% of spend to owned production. CAC stable, but contribution margin per order improved as paid spend leverage increased.

These are illustrative composites. Your numbers will differ. The structure - cadence + verification + decision - is the transferable part.

Reuse or fork? Decide once

SituationDo thisWhy
Same job, new contextReuse — change INPUT onlyThe META and OUTPUT contract already works; only your data changes.
New job, similar shapeFork — copy, then edit META + OUTPUTKeeps a proven skeleton while you adapt the goal and format.
One-off experimentDraft loosely, do not saveNot everything belongs in the library; save only what you will run again.

Treat META / INPUT / OUTPUT as composable blocks

  • META — the role and goal. Stable across runs; this is your reusable core.
  • INPUT — your bracketed context. The only part most runs should change.
  • OUTPUT — the contract: sections, length, format. Change this only when the deliverable changes.

3 rules for an internal prompt library

  1. One job per prompt. If it does two jobs, split it — each becomes reusable on its own.
  2. Explicit OUTPUT contract. Name the sections so any teammate scores the result the same way.
  3. A reviewer hook. Every prompt ends with a verify step before anything ships.

Version it for the team

Give each saved prompt a short name, a one-line "use when", and a date. When you improve it, bump the date and tell the team what changed. A named, dated prompt is a tool; an unnamed paste is a guess.

How to build your own chain

1
Name the outcome. One sentence: "every Friday we ship next week's priorities."
2
List the prompts in order. Each step's output feeds the next step's input.
3
Assign one owner. A chain without an owner is a wish, not a workflow.
4
Set the cadence. Weekly, per-launch, monthly — write it down so it survives a busy week.

CMO outcome. Repeatable process, not heroics. When a chain has a name, an owner, and a cadence, the result no longer depends on who is in the room.
